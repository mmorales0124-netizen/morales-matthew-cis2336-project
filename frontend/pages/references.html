References

Every image, resource, and AI prompt used while building ArtConnect, documented for transparency.

Image Sources

All six artworks displayed in the Gallery are the copyrighted work of their original artists. They are used here for a non-commercial school project with attribution, not claimed as original work.

  • "Cold Visions" — Album cover art

    Artist: Ville Nordström (Bladee). Used on the Gallery page as a "Not for Sale" featured piece, and featured on the Homepage.

  • Untitled — Painting

    Artist: Bladee x Varg2tm. Abstract mixed-media piece featuring repeated mask-like faces. Also featured on the Homepage.

  • "Loveless" — Album cover photography

    Photography: Angus Cameron. Album: My Bloody Valentine, Loveless, Creation Records, 1991. Also featured on the Homepage.

  • "E" — Poster artwork

    Artist: David Rappeneau. Created as poster/illustration artwork for Ecco2k's E EP (Year0001).

  • Soul Eater — Color illustration

    Artist: Atsushi Ohkubo, creator of the Soul Eater manga. Character depicted: Soul Evans.

  • Halloween Town — Windmill concept art

    Artist: Tim Burton. Concept/setting art associated with The Nightmare Before Christmas (1993).

External Resources Used

Fonts and tools used to build the site's front end and back end.

  • UnifrakturMaguntia (Google Fonts)

    Gothic blackletter display typeface used for the site wordmark and headings. fonts.google.com/specimen/UnifrakturMaguntia

  • Jost (Google Fonts)

    Geometric sans-serif used for body text throughout the site. fonts.google.com/specimen/Jost

  • Space Mono (Google Fonts)

    Monospace typeface used for navigation, labels, and metadata text. fonts.google.com/specimen/Space+Mono

  • Vanilla JavaScript

    No external JavaScript libraries or frameworks were used on the front end. All interactivity (nav toggle, gallery lightbox, FAQ accordion, event modal, booking form validation, submission form) is hand-written JS.

  • Lorem Picsum

    Free, royalty-free random stock photography used for event images on the Events page. picsum.photos

  • Node.js

    JavaScript runtime used to build the backend server. nodejs.org

  • Express

    Web framework used to build the backend's routing and request handling. expressjs.com

  • CORS (npm package)

    Middleware used to allow the frontend to make requests to the backend during local development. npmjs.com/package/cors

AI Prompts Used During Development

Claude (Anthropic) was used to help design and code the front end and back end. The prompts below summarize the requests made during development, in the order they were given.

Prompt 01 — Homepage

"Create a professional homepage for ArtConnect with a logo/title, navigation menu, welcome message, description, featured artwork section, featured event section, and a developer contact section."

Prompt 02 — Visual direction

"I want a dystopian visual direction, goth like the Cure, emo like Underoath, and inspired by Bladee's artwork and aesthetic."

Prompt 03 — Layout adjustment

"Center all the text below the 'Enter the Gallery' button."

Prompt 04 — Bug fix

"I opened it and I don't see the ArtConnect title with color" — requested a fix so the glitch/chromatic aberration effect on the title was visible.

Prompt 05 — Gallery page

"Create a gallery page displaying at least six artworks, each with image, title, artist, category, and price or 'Not for Sale,' enhanced with JavaScript for image enlargement."

Prompt 06 — Gallery layout

"Make the gallery grid show three artworks in one row and three on the next."

Prompt 07 — FAQ page

"Create an FAQ page with at least five questions that expand and collapse using JavaScript, visually organized and easy to navigate."

Prompt 08 — Style tweak

"Make 'Frequently Asked Questions' white."

Prompt 09 — References page

"Create a references page containing image sources, multimedia sources, external resources used, and AI prompts used during development."

Prompt 10 — Room booking form

"Develop a simple room booking form page (5 rooms). Develop validation checks for each room's availability (will be handled by the backend later). The form should follow best practices for validating form fields." — placed on the Events page.

Prompt 11 — Events page

"Create an events page displaying at least four upcoming art events, each with title, date, location, description, and image. JavaScript should be used to display event details dynamically. Use random images."

Prompt 12 — References update

"Can you update my references page" — requested addition of the Lorem Picsum image source and this updated prompt log.

Prompt 13 — Multimedia embed

Provided a YouTube link and asked for it to be embedded on the Gallery page, placed right under the intro text and before the artwork grid.

Prompt 14 — Video swap

"I switched it with this video, can you update my references" — swapped the embedded video to "Watch Yung Lean Make a Masterpiece" (Support for Yung Lean and Sadboys) after the first video threw a player error.

Prompt 15 — Artist Submission page

"Create a form that allows artists to submit artwork information: Artist Name, Email Address, Artwork Title, Category, Price, Description. Implement client-side validation for all required fields (empty-field, email, numeric, error messages). Form should not yet connect to the backend."

Prompt 16 — Backend setup

"Set up a backend service using Node.js and Express. Handle GET and POST requests. Process artwork submission form data. Store submitted artwork information temporarily in a JavaScript object or array on the backend. Return a confirmation message after successful submission." — requested step by step, with questions asked before each stage of building.

Prompt 17 — Backend route creation

"So first create those files for the backend?" — requested creation of the /api/artworks route with validation, in-memory storage, and confirmation responses.

Prompt 18 — Backend documentation

"For my readme can you documentation for the backend" — requested backend documentation (tech stack, endpoints, setup steps) merged into the existing project README.

Prompt 19 — Frontend/backend integration

"Now help me to integrate the backend to the frontend go step by step dont do it all once start at step one and ask me each time should i keep going" — requested connecting the Submit Art form (submit.js) to the real backend endpoint via fetch, one step at a time.

Prompt 20 — Homepage artwork fix

"Can you fix this weeks upload the artwork image placeholder just put images i put from their gallery and description any random 3" — requested replacing the placeholder Featured Artwork cards on the Homepage with real images and info from the Gallery page.

Prompt 21 — References update

"Can you add my AI prompts that i havent added yet" — requested this updated prompt log covering the backend and homepage work.
